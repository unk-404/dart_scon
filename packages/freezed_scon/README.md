# freezed_scon

Makes a **freezed** model speak SCON the same way it speaks JSON: the model
gains `toScon()` and a `<name>FromScon(text)` helper, generated into a **part
file** next to freezed's own generated parts.

```yaml
# consumer pubspec.yaml
dependencies:
  freezed_annotation: ^3.1.0
  json_annotation: ^4.9.0
  scon: ^0.1.0
dev_dependencies:
  build_runner: ^2.16.2
  freezed: ^4.0.2
  json_serializable: ^6.9.0
  freezed_scon: ^0.1.0
```

## Usage

```dart
import 'package:freezed_annotation/freezed_annotation.dart';
import 'package:freezed_scon/freezed_scon.dart';

part 'user.freezed.dart';
part 'user.g.dart';
part 'user.scon.dart'; // generated by freezed_scon

@freezed
@SconFreezed()
class User with _$User {
  const factory User({required String name, int? age}) = _User;

  factory User.fromJson(Map<String, dynamic> json) => _$UserFromJson(json);
}
```

`dart run build_runner build` writes `user.scon.dart`:

```dart
part of 'user.dart';

extension UserScon on User {
  String toScon() => encodeFreezed(this, (value) => value.toJson());
}

User userFromScon(String source) =>
    decodeFreezed(source, (json) => User.fromJson(json));
```

```dart
final text = user.toScon();
final back = userFromScon(text);
```

**Why a part file:** Dart has no way to add methods to an existing class from
another library, and the SCON methods must live in the class's own library — the
same reason `user.g.dart` exists. The part keeps the usage identical to JSON's
`toJson`/`User.fromJson`: no extra import, no wrapper type, no separate library.

## Requirements

- The class must expose `fromJson` and `toJson` (freezed + json_serializable:
  `@freezed`, `fromJson` factory, `part '*.g.dart'`).
- `@SconFreezed()` on the class.
- The `part '<name>.scon.dart';` directive (the generator fails loudly when it
  is missing or when the JSON members are absent).

Because the bridge goes through freezed's JSON mapping, `@JsonKey` renames and
json_serializable converters apply unchanged.

## Without codegen

For hand-written codecs the package also exports two helpers:

```dart
final text = encodeFreezed(user, (value) => value.toJson());
final back = decodeFreezed<User>(text, (json) => User.fromJson(json));
```

## Notes

- `freezed_scon` does not depend on freezed: it only inspects the members freezed
  generates, so a freezed upgrade does not require rebuilding this package.
- Generated parts can be committed (`build_to: source`); the builder never edits
  the source file.
- SCON's own limits apply (empty objects cannot be represented; see the `scon`
  README).
